# Pull Request Review Skill

Perform a code review of the github pull request on the current branch. Use the code-review skill in the official code-review plugin to do so. Add the code review in a details block in a comment in the PR.

Use the simple-english skill to explain the code review comments in a way that is easy to understand.

Add the header "## Automated Code Review" before the code review details.
